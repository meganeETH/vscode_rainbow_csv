# Swipe Shooter Puzzle

スワイプで狙ってボールを撃ち、数字付きブロックを壊す **Ballz / Bricks n Balls 風**の
モバイル向けパズルシューター（Godot 4.3）。外部アセット無し・GDScript のみで実装。

> ⚠️ **重要 / Status**: このゲーム設計は当初フォルダ名 `swipe-shooter-puzzle` からの
> **推測で決め打ち**したものです。**正式な仕様はまだ合意されていません**。
> 「このまま土台として使う / 作り直す」は未確定です（下記「未解決の論点」参照）。
>
> なお、このリポジトリは元々 **Rainbow CSV の VS Code 拡張**で、本ゲームはこの
> ブランチで新規に追加したものです。

## 遊び方

1. 画面を上方向に**スワイプして照準**（点線で反射軌道をプレビュー）、離すと**連射**
2. 数字付きブロックに当てて数字を減らし、**0で破壊**（＝スコア）
3. ブロックは1ターンごとに**下へ1段前進**。最下段の赤いラインに到達で**ゲームオーバー**
4. **「+1」オーブ**を取るとボールが増えて連射が強化
5. ゲームオーバー画面で**タップして再挑戦**

## 動かし方

### ローカル（Godot エディタ）
1. Godot **4.3 stable** で `swipe-shooter-puzzle/project.godot` を開く
2. F5（実行）。デスクトップではマウスがタッチとして扱われます
   （`emulate_touch_from_mouse`）

### Android デバッグ APK
- `main` / `claude/**` への push、または PR、もしくは手動実行（workflow_dispatch）で
  `.github/workflows/android.yml` が走り、APK をビルド
- 実行後の **Actions → artifact `swipe-shooter-puzzle-debug-apk`** からダウンロード
  （未署名デバッグ APK / arm64）

## 実装メモ

- 手動サブステップの**円 vs AABB 衝突**。速度一定化＋「ほぼ水平な弾」の補正を入れて、
  弾が左右の壁で無限に往復してターンが終わらない状態を防止
- 描画はすべて `_draw()` 内の `draw_*`（ブロック/数字/弾/HUD/ゲームオーバー）
- 状態機械: `AIM`（照準）→ `SHOOT`（発射・解決）→ `AIM` / `OVER`
